
### Full-screen portal (18 October 2026)

The chooser and listening view now occupy separate viewport screens. A brief logo intro respects reduced-motion settings. Selection actions animate into view only when the draft includes ajza; returning to the chooser pauses playback and retains the draft. Personal-playlist playback uses Teo’s playlist branding, without attributing other reciters to Yasser. Inline SVG transport controls replace platform-dependent text glyphs. Loop recording repeats the current video; switching it off restores continuous shuffled playback. The seek bar interpolates the YouTube clock between samples and supports touch, pointer cancellation, and keyboard jumps of five seconds.

Responsive checks covered 320×568 and 375×812 phone sizes, 768×1024, 1024×768, 820×1180 and 1180×820 tablet sizes, plus phone landscape. Visible player controls and the selection action fit within the viewport, with no document overflow. Native YouTube video controls remain available. These are browser viewport checks, not tests on physical iPad hardware.
