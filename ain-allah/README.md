# Ain Allah

Static Arabic/English reference page at `/ain-allah/`, using the existing Wycombe Dawah identity.

## Updating

Edit `evidence.json` for quotations and `wording.mjs` for the five explanatory topics, then run `node ain-allah/build.mjs` from the repository root. Commit both the data and generated HTML. Increase the CSS/JS version in `build.mjs` when changing those assets. No runtime package installation is needed.

The collection contains 45 source entries plus five explanatory topics: 27 distinct Qur'an verse references (including related passages), 12 reports from the two Sahih collections, 3 attributed reports of agreement, 6 early scholarly entries and 6 later scholarly entries. The six final reading-principle entries are included in the Quran total.

Keep Arabic quotations, the exact source reference, English meanings, excerpt markers and attribution notes together. Quran text was checked against Quran.com's Uthmani API. Hadith quotations were checked against the linked Arabic text. Classical statements were checked in the linked editions; this is not a new independent grading of all transmission chains. Modern official-source quotations are deliberately short.

Important distinctions: Zaynab's words are a Companion report; Abu al-Aliyah and Mujahid's explanations are al-Bukhari's chapter-heading citations; reports of consensus are attributed claims with a scope. Al-Dhahabi qualifies al-Sijzi's wording “bi-dhatihi” as an explanatory attribution by meaning. Preserve that qualification, also included when copying the passage.

The page remains readable without JavaScript. JavaScript adds Arabic/English search, reading controls, copying, print preparation and reading position. No analytics, external form submissions or storage are introduced.

Before publishing, check record IDs and source links, desktop/mobile rendering, search, copy, reading controls and the production page. Update the source-check date only after actually checking the content.

The wording section distinguishes the revealed word fawq from an English translation preference. Attribute the four istiwa glosses to Ibn al-Qayyim; do not claim unanimity for istiqrar or blanket weakness for all sitting reports. Sources document differences between al-Dhahabi, Ibn Uthaymin and al-Albani. Contact is not inferred or denied from an English preposition. Vocalized Qur'anic text is reused from the verified records; explanatory heading marks and short terms are separate from source quotations.
